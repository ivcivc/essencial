Regras do frontend

- O projeto não está na pasta raiz e sim na pasta /frontend

- Este projeto utiliza um template pronto (modelo) da Domiex em React JS 19
- Usar sempre YARN
- Documentação para devida utilização encontra-se em @web https://srbthemes.kcubeinfotech.com/domiex/docs/react-js/index.html
- Para conhecer todos os componentes do Domiex, pesquisar o projeto completo do template Domiex na raiz deste projeto na pasta /template-domiex.
- Usar o zod para validação e definição de esquemas.
